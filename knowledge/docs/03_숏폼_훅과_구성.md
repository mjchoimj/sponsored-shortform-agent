# 숏폼 노하우 — 훅과 구성

> 쇼츠·릴스(9:16, 60초 이하) 협찬 영상 기획용 일반 노하우.

## 첫 3초 — 훅

시청자는 첫 1~3초 안에 넘길지 정한다. 첫 씬은 **3초 이하**, **제품을 보여 주지 않는다**. 제품이 먼저 나오면 바로 광고로 읽혀 넘겨진다.

| 훅 유형 | 방식 | 예 |
|---|---|---|
| 문제 제기 | 시청자가 겪는 불편을 바로 보여 준다 | "빨래 이틀째 안 마름" |
| 질문형 | 시청자에게 직접 묻는다 | "아직도 선크림 손으로 문질러 발라?" |
| 지적·잔소리형 | 잘못된 습관을 짚는다 | "야, 그렇게 바르면 다 밀려" |
| 비포·애프터 | 결과를 먼저 보여 준다 | 정리 전 방 → 정리 후 방 컷 |
| 숫자형 | 구체적 숫자로 시작 | "출근 준비 5분, 진짜 됩니다" |
| 공감형 | 시청자의 상황에 말을 건다 | "퇴근하고 오셨죠?" |

채널마다 늘 쓰는 오프닝(시그니처 멘트)이 있으면, 훅 바로 뒤나 훅 안에 자연스럽게 넣는다. 시그니처를 훅보다 길게 늘이지 않는다.

## 길이별 구성

| 길이 | 씬 수(권장) | 영상에 넣을 포인트 | 구성 |
|---|---|---|---|
| 15초 | 3~4 | 최대 2개 | 훅 → 핵심 장면 → 마무리 한 마디 |
| 30초 | 5~6 | 최대 3개 | 훅 → 문제 → 포인트 2~3개 → 마무리 |
| 45초 | 6~8 | 최대 4개 | 훅 → 문제 → 포인트 → 사용 장면 → 정리 |
| 60초 | 8~10 | 최대 5개 | 훅 → 문제 → 포인트 → 사용 장면 → 비교·정리 → 마무리 |

영상에 다 넣지 못한 포인트는 **설명란**에 적는다. 포인트를 억지로 다 넣으면 씬마다 1~2초가 되어 아무것도 기억에 남지 않는다.

## 제품 노출 비율

제품이 화면에 나오는 시간은 전체의 **30% 이하**로 한다. 나머지는 상황, 사람, 결과를 보여 준다.
"제품을 쓰는 장면"보다 "제품 덕에 달라진 결과"가 광고 거부감이 적다.

## 마무리

- 마지막 씬에 채널 시그니처 엔딩 멘트를 넣는다.
- "링크는 설명란에" 같은 행동 유도는 짧게 한 번만.
- 광고 표시는 업로드 패키지(제목 또는 설명란 첫 줄)에 넣고, 영상 자막에는 "유료광고 포함"을 권장한다.
