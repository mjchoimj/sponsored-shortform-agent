# 채널 톤 유지와 광고주 요구 조율

> 협찬 영상이 "광고 같다"는 반응을 얻는 가장 큰 이유는 채널 평소 말투가 깨지는 것이다.

## 말투

- 채널이 반말이면 대사·자막 전체를 반말로, 존댓말이면 전체를 존댓말로 쓴다. 광고주 문구("~합니다", "~를 경험하세요")를 그대로 옮기지 않는다.
- 광고주 문구는 채널 말투로 **다시 말한다**. 예: "저소음 설계로 숙면을 방해하지 않습니다" → (반말) "밤에 켜 놔도 거의 안 들려" / (존댓말) "밤에 켜 두셔도 거의 안 들려요".
- 자막의 짧은 문구("꿀팁 대방출", "3분 컷")는 말투가 없으니 그대로 써도 된다.

## 채널 대표 포맷

평소 영상 흐름(예: 문제 상황 → 꿀팁 → 비용 비교)에 제품을 끼워 넣는 것이 가장 자연스럽다. 협찬이라고 흐름을 바꾸면 구독자가 바로 알아챈다.

## 광고주 요구가 무리할 때 — 제안 방식

| 상황 | 제안 |
|---|---|
| 포인트가 너무 많다 | 상위 포인트만 영상에, 나머지는 설명란에. 광고주에게는 "설명란에 전부 들어간다"고 안내 |
| 과정을 전부 보여 달라 (설정 7단계 등) | 핵심 1~2단계만 영상에, 전체 단계는 설명란에 순서대로 |
| 제품을 오래 보여 달라 | 노출 30% 규칙 우선. 대신 제품 덕에 달라진 결과를 길게 보여 준다 |
| 서로 모순되는 포인트 (최저가 + 최고급) | 하나만 고른다. 채널 콘셉트와 제품 설명에 맞는 쪽 |
| 채널 정체성과 충돌 (솔직 리뷰 채널에 단점 금지) | 톤은 유지하고, 단점은 "이렇게 쓰면 더 좋다"는 사용 팁으로 바꾼다 |
| 채널 콘셉트와 다른 연출 (5분 출근 채널에 풀메이크업) | 채널 콘셉트 안에서 보여 주고, 다른 활용은 설명란에 짧게 |
| 과장 표현 ("피부가 새로 태어나요") | 규정에 맞는 완화 표현으로 ("피부 결이 정돈돼 보여요") |

## 솔직함의 범위

- 단점을 말해도 광고 효과는 크게 떨어지지 않고, 오히려 신뢰가 올라간다.
- 단, 제품 설명에 없는 단점을 지어내지 않는다. 사실에 근거한 아쉬운 점과 그 보완 팁만 말한다.
