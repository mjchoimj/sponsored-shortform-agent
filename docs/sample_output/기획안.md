# 협찬 숏폼 기획안 — 포근 보풀 제거기

- 채널: 오늘도 자취중 (반말) · 길이 30초 · 카테고리 생활용품
- 상태: ✅ 검증 통과 · 수정 0회 · 최종 승인: 예

## 기획안 요약
**1안 · 니트 보풀 문제, 이 방법이 정답** (훅: 문제 제기)

> 니트 입을 때마다 보풀이 솟아나는데, 너무 거슬려

니트 보풀의 불편함을 언급한 후, 기존 방법(손으로 뜯기, 면도기 등)의 한계를 설명하고, 포근 보풀 제거기의 3단 높이 조절과 충전식 편리함을 자취생 입장에서 소개한다. 마지막으로 건전지 비용을 아끼는 효과까지 덧붙인다.

영상 포인트: USB-C 충전식이라 건전지 필요 없음 / 3단 높이 조절로 니트도 안전하게 / 보풀 통이 커서 비우기 편함

반영한 수정 요청 (사람 검토):
- 제목에 가격 15,900원을 넣고, 마지막 씬 대사를 더 짧게 해 주세요
